## PCBA Partner

PCB assembly in Dongguan, China, since 2009. ISO 9001:2015 certified. Orders from 1 board, no minimum order quantity.

We publish small, reproducible teaching packs for checking the files you send to an assembler. They are free to use and reuse.

| Repository | What it is | License |
| --- | --- | --- |
| [gerber-layer-checks-teaching-pack](https://github.com/pcbapartner/gerber-layer-checks-teaching-pack) | Three KiCad 10 Gerber exports: original, missing outline, and a copper file whose name conflicts with its X2 attributes | MIT |
| [kicad-export-compatibility-teaching-pack](https://github.com/pcbapartner/kicad-export-compatibility-teaching-pack) | KiCad 10.0.6 project with unedited BOM and placement exports plus expected import results | MIT |
| [pcba-fabrication-toolkit](https://github.com/pcbapartner/pcba-fabrication-toolkit) | KiCad plugin that exports Gerber/drill ZIP, BOM, CPL and a pre-flight report (testing release) | GPL-3.0-or-later |
